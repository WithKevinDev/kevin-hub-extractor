❓ Frequently Asked Questions

What is Extract Sources?

A free tool that extracts ALL files from ZIP archives (any extension) and sends them directly to your Discord channel via webhook. Nested ZIPs are fully supported.

How do I use it?

1. Enter your Discord Webhook URL
2. Upload a ZIP file
3. Click "EXTRACT & SEND"
4. Files are sent one by one with a 0.30s delay.

Can I stop midway?

Yes! Click the red "STOP" button at any time. The current file will finish sending, then the process halts immediately.

What about duplicate files?

By default, duplicate filenames (case-insensitive) are skipped — only the first occurrence is sent. You can disable this in the options.

Is there a file size limit?

Maximum archive size is ~100MB (Cloudflare Worker limit). Individual files must be under 25MB (Discord limit).

Is this service free?

✅ Yes! Completely free and runs 24/7 on Cloudflare Workers.
